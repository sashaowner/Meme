# MEME SCOUT

Static first version of the Meme Scout website.

## Upload to GitHub
Upload `index.html`, `styles.css`, `script.js`, and `mascot.png` to the repository root.

## After token launch
Open `script.js` and replace:
- `BUY_URL` with the DEX/token URL
- `TWITTER_URL` with the X/Twitter URL
- `TELEGRAM_URL` with the Telegram URL

## Embedded tool
The page currently embeds `https://zksync.netlify.app/robinhood` and also provides an Open Full button.

## GitHub Pages
Repository Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
